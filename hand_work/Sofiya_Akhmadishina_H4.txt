Part a Keep all three rows tight

y1 + y2 = 1 + epsilon
y2 + y3 = 1
y1 + y3 = 1

Subtracting the last two equations gives y1 = y2. The first equation then gives y1 = y2 = (1 + epsilon) / 2. Substitution gives y3 = (1 - epsilon) / 2.

The objective becomes
z(1 + epsilon) = 8(1 + epsilon)/2 + 7(1 + epsilon)/2 + 7(1 - epsilon)/2
= 11 + 4 epsilon.

The slope is 4.000 which equals the assigned first price pi1 = 4.000. The same nonnegative dual vector (4,3,4) has reduced costs zero and gives the bound 4(1 + epsilon) + 3 + 4 = 11 + 4 epsilon. Our feasible point reaches it so the point is optimal throughout its validity interval.

Part b Bound validity

The bounds on y1 and y2 require 0 <= (1 + epsilon)/2 <= 1 which means -1 <= epsilon <= 1. The bounds on y3 require 0 <= (1 - epsilon)/2 <= 1 which gives the same interval. Thus the full interval is [-1,1].
