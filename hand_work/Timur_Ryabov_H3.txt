Appendix H3 Checking the two dual vectors

Use y = (0.500,0.500,0.500) and c = (8,7,7). All rows are >= rows so every row price must be nonnegative. All three row slacks are zero and every variable is interior.

Part a Assigned vector pi = (4,3,4)

A^T pi = (4+4,4+3,3+4) = (8,7,7). Reduced costs r = c - A^T pi = (0,0,0). The bound term sum min(0,r_j) is zero. The primal cost is 11 and the dual value is 4+3+4 = 11.

Part b Alternative vector pi prime = (5,2,3)

A^T pi prime = (5+3,5+2,2+3) = (8,7,5). Reduced costs are (0,0,2). All prices remain nonnegative. The dual value is 5+2+3 = 10 because the bound term is still zero.

Part c The weaker lower bound

Since pi prime >= 0 and A^T pi prime <= c we have c^T y >= pi prime^T Ay >= pi prime^T b = 10 for every feasible nonnegative y. Therefore 10 is a valid lower bound even though it is not optimal. It is 1.000 below the best lower bound of 11.000. The failure is reduced cost stationarity at the proposed half point rather than invalid row signs.
